# farm: coloring app (cow, pig, chicken, sheep, barn, tractor)

Eighth app, cloned from `apps/space` with `tools/new_app.py`. Same engine, new
content pack: pictures from `tools/make_pictures.py`, text in `assets/i18n/`.
Package id after bootstrap: `com.marcdooo.farm`.

Store text and images live in `store/`. Regenerate images with
`python3 tools/make_store_assets.py`. See `/PUBLISHING.md` at the repo root.
